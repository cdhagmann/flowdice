# Rails Skeleton + Packwerk + /parse — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a Rails 8 app around the existing `FlowDice::Engine`, wire the engine in as a Zeitwerk-autoloaded, dependency-enforced Packwerk pack, and expose a stateless `POST /parse` endpoint.

**Architecture:** Vanilla Rails 8 (`rails new . --skip-test`; SQLite/AR/Solid, importmap, Propshaft/plain CSS, Hotwire, PWA stubs). The engine is restructured to be Zeitwerk-conformant (one constant per file) and added to `autoload_paths`; Packwerk enforces dependency direction (root → `packs/dice_engine`). `ParseController` calls `FlowDice::Engine.parse` and returns JSON.

**Tech Stack:** Ruby 3.3+, Rails 8, RSpec (rspec-rails), Packwerk, Zeitwerk, importmap, Propshaft.

**Working directory:** the repo root `/Users/christopherhagmann/Projects/Personal/flowdice` (a worktree of it at execution time). All paths are relative to the repo root.

**Preconditions:** network access (for `bundle install` of Rails). The engine is on `main` with 82 passing specs (drops to 81 after Task 3 removes the version spec).

  end

  it "returns 422 when notation is missing" do

- [ ] **Step 4: Implement the controller**

`app/controllers/parse_controller.rb`:
```ruby
# frozen_string_literal: true

class ParseController < ApplicationController
  # Stateless JSON API; no CSRF token (no session/mutation).
  skip_forgery_protection

  def create
    parsed = FlowDice::Engine.parse(params.require(:notation))
    render json: {
      notation: parsed.notation,
      plan: parsed.plan,
      explanation: parsed.explanation
    }
  rescue FlowDice::ParseError, ActionController::ParameterMissing => e
    render json: { error: e.message }, status: :unprocessable_entity
  end
end
```
